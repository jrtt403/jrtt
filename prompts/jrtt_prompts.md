# 今日头条 AI 辅助创作提示词

## 账号定位

普通人看懂中外热点背后的影响。

## 热点事实卡片

```text
请根据以下新闻链接和内容，整理事实卡片。
要求：
1. 只保留已确认事实
2. 标注来源
3. 区分事实、观点、推测
4. 不生成标题党表达
5. 输出：事件概述、时间线、相关方、争议点、待确认信息、可写角度
```

## 选题评分

```text
请从今日头条创作者视角，对以下热点进行选题评分。
评分维度：热度、时效性、普通人相关性、可解释空间、账号定位匹配度、合规风险。
账号定位：普通人看懂中外热点背后的影响。
请输出评分、推荐理由、风险提醒、建议标题方向。
```

## 正文生成

```text
请基于事实卡片和我的观点，写一篇今日头条图文草稿。
要求：
1. 不是新闻搬运，要体现解释和分析
2. 不编造事实
3. 不使用夸张标题党
4. 语气平实、有判断
5. 字数 1200-1800 字
6. 结构：开头观点、事实背景、影响分析、普通人视角、后续观察
7. 对不确定内容明确写“仍需观察”或“不宜过早下结论”
```

## 标题优化

```text
请为以下文章生成 10 个今日头条标题。
要求：
1. 标题要有判断，但不能夸张
2. 避免“震惊、彻底变天、内幕曝光、刚刚”等标题党词汇
3. 每个标题不超过 28 个汉字
4. 输出标题、适合人群、风险提醒
```
